# MyMail

A fully local email app for macOS: a native **SwiftUI** client, a **Rust** backend (axum + a small SMTP receiver) and a **SQLite** database. Nothing leaves your machine.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the design and the full HTTP API.

## Requirements

- macOS 14+
- Rust (`cargo`) and Swift 5.10+ (Xcode Command Line Tools are enough)

## Run

```bash
./scripts/run.sh
```

This builds both halves, assembles `build/MyMail.app`, and opens it. The app starts the bundled server when it launches and stops it when you quit. Mail is stored in `data/mymail.db`.

On first run the database is seeded with three local accounts: `me@mymail.local`, `alice@mymail.local` and `bob@mymail.local`. Switch between them in the sidebar to see mail arrive on the other side.

Keyboard shortcuts: ⌘N new message, ⌘R reply, ⇧⌘R reply all, ⇧⌘F forward, ⇧⌘N get new mail, ⌘⌫ delete.

If only Command Line Tools are installed, `build.sh` automatically builds against the newest macOS 26 SDK. The macOS 27 SDK needs a SwiftUI macro plugin that Command Line Tools don't include. You can override this by setting `SDKROOT`.

## Build from a fresh clone

Build output is not committed. These are all regenerated by `./scripts/build.sh` (or `./scripts/run.sh`):

| Not in git | Regenerate with |
|---|---|
| `backend/target/` | `cargo build --release --manifest-path backend/Cargo.toml` |
| `app/.build/` | `swift build -c release --package-path app` |
| `build/MyMail.app` | `./scripts/build.sh` |
| `data/` (SQLite DB, server log) | Created and seeded on first launch |

Steps:

1. Install the Xcode Command Line Tools (`xcode-select --install`) and Rust (`curl https://sh.rustup.rs -sSf | sh`).
2. `git clone <repo> MyMail && cd MyMail`
3. `./scripts/run.sh` builds both halves, assembles `build/MyMail.app`, and opens it.

## Other scripts

| Command | What it does |
|---|---|
| `./scripts/build.sh` | Build only (produces `build/MyMail.app`) |
| `./scripts/server.sh` | Run only the backend in the foreground against `data/mymail.db` |
| `swift scripts/make-icon.swift` | Regenerate `assets/AppIcon.icns` |

## Sending mail in from other tools

The server accepts SMTP on `127.0.0.1:2525` for any local account:

```bash
printf 'From: Script <bot@example.com>\r\nTo: me@mymail.local\r\nSubject: Hello from curl\r\n\r\nIt works!\r\n' > /tmp/msg.eml
curl smtp://127.0.0.1:2525 --mail-from bot@example.com --mail-rcpt me@mymail.local -T /tmp/msg.eml
```

## Limitations

- Mail only goes to local accounts. Anything sent to an outside address is saved in Sent and flagged as undelivered, because there's no outbound relay and no IMAP sync.
- The server only listens on loopback and has no authentication, so it's meant for single-user local use.
- To reset everything, quit the app and delete `data/`.
